Will Eric see my private files?

Eric will see whatever’s on your screen — the same as if he were standing next to you. Close anything personal before connecting, and remember you can end the session any time by closing the window.

My browser warned me about the download. Is it safe?

Yes. The tool is TeamViewer QuickSupport with iDezign branding — the same software used by IT support shops worldwide. Some browsers warn about any downloaded .exe, but this one is signed and verified.

How long does a session usually take?

What if I’m not in front of my computer?
